## 一句话概念

`ScifiWorlds` 是一款科幻题材的多人联机第三人称技能射击推塔游戏：玩家操控拥有独特射击方式和专属技能的角色，通过战斗、装备构筑与三路推进，最终摧毁敌方水晶取得胜利。

## 项目目标

- 以 `Deadlock` 为主要研究参照，对其第三人称英雄射击与多路推塔机制进行拆解，并完成具有原创角色、系统和内容表达的重构。
- 验证“角色差异化射击 + 专属技能 + 装备改变技能属性 + 三路推塔”这一核心组合的可玩性与构筑深度。
- 交付一个可通过 Dedicated Server 完成多人对局的可玩 Demo。

## 目标玩家

- 核心用户：偏好第三人称射击、英雄技能协作、装备构筑与团队推塔玩法的玩家。
- 玩家需求：角色操作差异、技能组合与构筑选择、团队对抗和明确的推进目标。
- 预期游戏时长：TBD

## 核心体验支柱

1. **角色与射击差异化：** 每个角色拥有不同的射击方式和专属技能，形成明确的操作手感、战斗定位与团队价值。
2. **技能导向的装备构筑：** 装备可修改适用技能的伤害、持续时间、作用范围、冷却时间和可用次数等属性；仅拥有对应特性的技能受到相应修正。
3. **三路团队推进：** 对称地图包含三条路线，双方小兵周期生成并沿路线推进；团队通过射击、技能、装备成长与路线运营突破防御，最终摧毁敌方水晶。

## 核心玩法循环

`选择角色 → 进入路线并对抗小兵/敌方玩家 → 获取资源并购买装备 → 强化适用技能属性 → 推进三路并摧毁防御目标 → 摧毁敌方水晶`

## 当前功能范围

- 多名玩家能够连接到同一 Dedicated Server 并完成一场对局。
- 可操控角色拥有自己的射击方式和专属技能集合。
- 装备系统能够按技能实际支持的特性修改伤害、持续时间、范围、冷却或次数等属性。
- 对局地图采用双方对称的三路结构。
- 每条路线能够周期生成双方小兵并驱动其沿路线推进与战斗。
- 对局包含可被逐步推进的防御目标，以及作为最终胜利目标的双方水晶。
- 服务器权威判定敌方水晶被摧毁并结束对局。

功能实现顺序以 `07_DevelopmentRoadmap.md` 的系统依赖为准，不额外维护 Must/Should/Could 优先级矩阵。

## 终止或重新评估条件

- 核心玩法原型无法形成可验证的射击、技能、装备与推塔闭环。
- 技术方案无法在目标 Dedicated Server 环境中满足基本可玩性或维护成本失控。
- 出现无法通过缩减功能范围缓解的资产许可、平台或资金风险。
